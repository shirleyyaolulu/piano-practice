# 幼儿钢琴练习助手

孩子刚开始学钢琴，每周上一次课，回家该怎么练？练什么？练多久？

这个工具就是来解决这个问题的。你不需要懂钢琴，只要上完课后告诉我老师教了什么，我来帮你安排每天的练习——而且是孩子愿意练的那种。

## 怎么用

把这个 skill 加到你使用的 AI agent 里，然后用 `/piano-practice` 调用，或者直接说跟练琴相关的话就行：

```
今天上完课了，老师教了越过山坡
```

```
今天练什么
```

```
孩子不想练琴怎么办
```

只要你的话里包含"练琴""钢琴练习""今天练什么""上完课了"这类关键词，助手就会自动启动。

## 日常使用流程

整个流程很简单，跟着下面三步走就行：

### 1. 上完课 → 告诉我学了什么

每周上完钢琴课，跟我说一声：

> "今天上课了，老师教了越过山坡，还学了什么是拍号"

我会问你几个问题（老师布置了什么作业、有没有特别提醒什么），然后帮你记下来。你不用记格式，就像聊天一样说就好。

### 2. 想练琴 → 问我今天练什么

到了练琴时间，直接问：

> "今天练什么"

我会根据这周学的新内容，加上之前学过但该复习的旧内容，给你一份 20-25 分钟的练习计划。每个环节都写了具体怎么做、该观察什么、如果孩子卡住了怎么办。

不用担心旧的内容会忘——我会自动安排复习，学过的东西会隔几天出现一次，慢慢拉长间隔，直到真正记住。

### 3. 练完了 → 告诉我练得怎么样

练完之后说一声：

> "练完了，越过山坡基本能弹下来，左手拍球还有点不熟"

我会根据你的反馈调整后续的练习安排——练得好的内容会减少出现频率，不太熟的会多安排几次。

## 还能帮你做什么

除了上面的日常流程，你还可以这样用：

| 你想做的 | 怎么说 |
|---------|-------|
| 安排一整周的练习 | "帮我排一下这周的练习计划" |
| 孩子不想练琴 | "孩子不愿意练怎么办"或"来个故事练琴" |
| 某个地方总弹不好 | "越过山坡中间那段老是卡住" |
| 之前记错了想改 | "上次记的曲子名字不对，帮我改一下" |
| 看看学了多少 | "跳跳现在学了哪些东西了" |

## 练习计划长什么样

每天的练习大概 20-25 分钟，分成几个小环节：

- **热身**（约5分钟）：用之前学过的内容热热身，顺便复习
- **主线任务**（约10分钟）：这周的重点内容，分成小步骤，一步一步来
- **回忆挑战**（约5分钟）：拿一首以前的曲子出来弹弹，看还记不记得
- **收尾**（约2分钟）：轻松结束，回顾今天做了什么

每个环节都会告诉你：练什么、怎么练、家长该观察什么、如果孩子觉得难该怎么降级。

如果排一整周的计划，每天会有不同的主题——有重点练习的日子，也有纯玩游戏的日子，还有一天是可以完全不练的自由日。

## 数据说明

所有学习记录保存在 `data/progress.json` 里。这个文件会自动创建和更新，你不需要手动编辑它。它记录了：

- 每周上课学了什么
- 所有学过的曲子和技能点
- 每项内容的熟练程度和上次复习时间

每周的练习计划会保存在 `data/weekly-plans/` 目录下，是 Markdown 文件，你可以用任何文本编辑器打开，也可以打印出来放在钢琴旁边。

## 几个你可能想知道的事

**我不懂钢琴，能用吗？**
完全可以。所有提示都是写给不懂钢琴的家长看的。音乐术语都会用大白话解释（比如"连奏"就是"手指唱歌，弹了这个音不松手直到弹下一个"）。

**孩子今天就是不想练怎么办？**
没关系。可以换成听音乐、画音符、拍手打节奏这些不用弹琴的活动。保持兴趣比练习量重要得多。

**这个能代替钢琴老师吗？**
不能。这是课间辅助工具，帮你把老师教的内容在家里巩固好。遇到拿不准的问题，记下来下次课问老师。

**用了多久会忘记之前学了什么？**
不会。所有学过的内容都有记录，我会自动安排复习。新学的内容每天都会出现，熟练了以后慢慢降到每周一次、每两周一次。

**孩子的进度跟别人不一样正常吗？**
完全正常。4-6岁的孩子进度差异很大，快慢都没关系，按自己的节奏来就好。

**想换台电脑用怎么办？**
把整个 `piano-practice` 文件夹（特别是 `data/` 目录）复制到新电脑的同样位置就行。所有学习记录都在 `data/progress.json` 里，搬过去就能接着用。
