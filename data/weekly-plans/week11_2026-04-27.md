# 跳跳的钢琴练习计划 — 第11周

**日期**：2026/4/28（周一）— 2026/5/3（周六）

**上课日**：周日 5/4

**每日时间**：晚上 8:15，约 20-25 分钟

**演奏阶段**：五指位置期（继续巩固左右手 1-2-3 指弹奏）

---

## 本周重点

| 类别 | 内容 |
| --- | --- |
| 新乐理 | 休止符（全休止符、附点二分休止符、二分休止符、四分休止符）、旋律音程、和声音程 |
| 新曲目 | 天天练练《轻轻跳》、天天练练《深呼吸》 |
| 预习 | 《滑稽面孔》（本周作业，下次课前认识一下） |
| 继续巩固 | 《排钟》（老师强调多练）、《雷格泰姆舞》（全曲）、低音谱号 so、三四拍强弱弱 |
| 复习曲目 | 翻滚、左手拍球、右手拍球、越过山坡、海军修建兵、玛丽有只小羊羔、火车、小矮人舞曲、小矮人进行曲 |
| 复习技巧 | 手型小拱桥、弧线跳音、切分节奏、小节线和终止线 |

**本周练习配方**：新内容 55% + 到期复习 30% + 轻松回顾 15%

**本周特别关注**：
- 休止符是全新概念——"音符的请假条"，用孩子记住的形象来巩固（M、吸顶灯、巧克力蛋糕）
- 老师还教了一种不靠形状的辨别方法：小节里没有其他休止符→全休止符，有其他休止符→二分休止符；四分和附点二分靠形状区分
- 音程分两种：旋律音程（一个一个弹）和和声音程（两个一起弹），通过"听"来区分
- 天天练练的《轻轻跳》和《深呼吸》是新曲，需要每天练
- 《滑稽面孔》是预习作业，周末之前认识一下就好，不要求弹熟
- 《排钟》继续是重点曲目，结合三四拍强弱弱一起练
- **手型重点关注**：手还是容易塌；弹低音谱号 so 时食指中指容易翘起来。每天热身加入"手指按住不翘"的小练习

### 环节一：热身（5分钟）— 小拱桥 + 手指不翘练习

- [ ] 右手 1-2-3 指放在 Do-Re-Mi 上，慢慢弹 Do-Re-Mi-Re-Do x 3
- [ ] 左手 1-2-3 指在低音区也来一次 x 3
- [ ] 弹之前先说一句："小拱桥搭好，苹果不掉下来"
- [ ] **手指不翘练习**：左手弹低音 so 时，另外两根手指（食指、中指）轻轻放在旁边的键上不抬起来，保持 3 秒 x 3 次

> **家长看这里**：跳跳弹低音 so 的时候，食指和中指容易翘起来。这是因为手指独立性还在发展，很正常。练习方法：弹 so 的时候，让不弹的手指"睡觉"——轻轻贴在琴键上，不用按下去，但也不要翘起来。一开始能做到一两次就行，不用每次都纠正。

### 环节二：主线任务（10分钟）— 休止符大集合

今天的重头戏是认识"音符的请假条"——休止符！

- [ ] 家长说："上课学了音符的请假条，还记得叫什么吗？"（休止符）
- [ ] 一起回忆四种休止符的样子：
  - 四分休止符 → "像横过来的 M"
  - 全休止符 → "像吸顶灯"（挂在线下面）
  - 二分休止符 → "像巧克力蛋糕"（坐在线上面）
  - 附点二分休止符 → 巧克力蛋糕旁边加个小圆点
- [ ] 家长画或指出每种休止符，跳跳说出名字 x 2 轮
- [ ] 家长说一种休止符名字，跳跳用手比划它的样子 x 3 次

> **家长看这里**：今天只需要"认脸"——看到样子能说出名字就很棒了。不用记住具体多少拍，那个后面再巩固。用孩子自己记住的比喻最有效。

## 周二 4/29 — 轻松日

> 今天轻一点，用听和玩的方式感受"音程"，顺便继续练排钟。

---

### 三选一即可（10-15分钟）

#### 选项 A：音程听听看

- [ ] 家长在钢琴上先后弹两个音（如 Do 然后 Mi）→ 问跳跳："这两个音是一起响的还是一个一个响的？"（一个一个 = 旋律音程）
- [ ] 家长同时按下两个音（如 Do 和 Mi）→ 再问同样的问题（一起响 = 和声音程）
- [ ] 重复 3-4 组，跳跳判断是"排排走"（旋律音程）还是"手拉手"（和声音程）
- [ ] 弹《排钟》1 遍

#### 选项 B：排钟 + 强弱弱

- [ ] 先拍三四拍"强 弱 弱" 4 组
- [ ] 弹《排钟》1-2 遍
- [ ] 试着边弹边轻轻数"1 2 3"

- [ ] 弹《深呼吸》1 遍

## 周三 4/30 — 主练日

> 今天是本周最重要的一次练习：休止符配合乐谱理解 + 雷格泰姆舞和排钟精练。

---

### 环节一：热身（4分钟）— 休止符快问快答 + 手指不翘

- [ ] 家长说"吸顶灯" → 跳跳答"全休止符"
- [ ] 家长说"巧克力蛋糕" → 跳跳答"二分休止符"
- [ ] 家长说"横过来的M" → 跳跳答"四分休止符"
- [ ] 反过来：家长说休止符名字，跳跳说像什么
- [ ] 右手 1-2-3 指弹 Do-Re-Mi-Re-Do x 3（手型检查）
- [ ] **手指不翘练习**：左手弹低音 so，食指中指"睡觉"贴键 x 3 次

> **家长看这里**：快问快答可以很快完成，答不出来就给提示，不要变成考试。手指不翘练习每天做一点就行。

---

### 环节二：主线任务（10分钟）— 雷格泰姆舞 + 排钟

- [ ] 唱谱《雷格泰姆舞》1 遍
- [ ] 弹《雷格泰姆舞》全曲 2-3 遍（第10周已经很流畅了，保持手感）
- [ ] 找到曲谱里有没有休止符，指出来
- [ ] 弹《排钟》2-3 遍
- [ ] 弹排钟时试着在休止符处停住不弹

> **家长看这里**：雷格泰姆舞上周已经很流畅了，这周弹 2-3 遍保持手感就好。排钟也基本熟了，多弹几遍巩固。今天的目标是让跳跳在实际曲谱里"看到"休止符。不要求弹得完美，能指出来就很好。排钟里如果有休止的地方，提醒"这里音符请假了，要安静等一下"。

---

### 环节三：音程小实验（4分钟）

- [ ] 家长弹两个音（先后弹）→ 问"排排走还是手拉手？"（旋律音程）
- [ ] 家长弹两个音（同时弹）→ 再问（和声音程）
- [ ] 跳跳自己试：先"排排走"弹 Do-Mi，再"手拉手"同时按 Do 和 Mi
- [ ] 问跳跳："哪种听起来更丰满/饱满？"

> **家长看这里**：音程不需要记名字（二度、三度这些），只要能分清"一个一个弹"和"一起弹"就足够了。

## 周五 5/2 — 冒险日：休止符精灵和音程桥

> 今天用故事模式，把休止符、音程和本周的曲子串起来。

---

### 第一章：休止符精灵的考验（5分钟）

家长读给跳跳听：

> *"跳跳来到音乐森林，遇到了四个小精灵。它们说：'我们是休止符精灵！音符们弹累了就来找我们请假休息。你还记得我们长什么样吗？'"*

任务：
- [ ] 说出四种休止符的名字和样子
- [ ] 精灵说："我来考考你！"→ 家长随机说 3 个，跳跳比划或回答
- [ ] 通过考验！精灵送跳跳一把"安静钥匙"

---

### 第二章：音程桥的选择（5分钟）

> *"跳跳拿着安静钥匙来到一座桥前。桥上有两条路：一条是'排排走'的路（旋律音程），一条是'手拉手'的路（和声音程）。要过桥，两条路都要走一次！"*

任务：
- [ ] "排排走"：先后弹 Do-Mi，再先后弹 Re-Fa，各 2 次
- [ ] "手拉手"：同时按 Do+Mi，再同时按 Re+Fa，各 2 次
- [ ] 跳跳选一条路再走一次（弹一次）

---

### 第三章：排钟城堡和爵士舞会（8分钟）

> *"过了桥，跳跳先到排钟城堡。城堡里的钟在唱强—弱—弱的歌。然后爵士森林传来音乐，是雷格泰姆舞会又开始了！"*

任务：
- [ ] 拍"强 弱 弱" 4 组
- [ ] 弹《排钟》2-3 遍
- [ ] 弹《雷格泰姆舞》2 遍（能弹多少算多少）
- [ ] 弹《轻轻跳》或《深呼吸》2-3 遍
