## 周一 5/11 — 巩固日

> 昨天刚上完课，今天先把新内容都“见一面”，不用追求完美，先建立熟悉感。

### 环节一：热身（5分钟）— 小拱桥 + 左手唤醒

- [ ]  右手五指轻轻放好，慢慢弹 Do-Re-Mi-Re-Do x 2
- [ ]  左手也慢慢来一次 x 2
- [ ]  弹之前说一句：“小拱桥搭好，左手也会自己工作”
- [ ]  左手在键上轻轻站好，单独动一根手指按一下，再放开 x 5 次

> **家长看这里**：今天热身重点不是声音大不大，而是看手有没有塌、左手会不会一按就整只手都乱动。能慢慢控制一点点，就是进步。

### 环节二：主线任务（10分钟）— 《扬基歌》+《教堂管风琴》

- [ ]  先唱《扬基歌》1-2 遍，遇到 `Si-So-Fa` 的地方慢慢唱
- [ ]  慢速弹《扬基歌》3 遍
- [ ]  弹《教堂管风琴》2-3 遍，目标是不断、不卡住
- [ ]  如果《扬基歌》有卡住的 3 个音，就单独拿出来再唱 2 次、再弹 2 次

> **家长看这里**：《扬基歌》先唱再弹会轻松很多，别急着快。《教堂管风琴》今天的任务只是“慢慢连起来”，不是弹熟。

### 环节三：天天练新内容（3分钟）

- [ ]  弹《左手举锤敲击》3 遍
- [ ]  弹《穿雨鞋在水中行走》2 遍

### 环节四：收尾（2分钟）

- [ ]  弹《深呼吸》1 遍放松
- [ ]  夸一句：“今天认识了好多新朋友，已经很棒了！”

## 周二 5/12 — 主练日

> 今天把最容易混淆的地方拿出来练清楚：`Si-So-Fa` 和 `高音 Fa / 低音 So`。

### 环节一：热身（5分钟）— 找音游戏

- [ ]  家长说 “高音 Fa”，跳跳在琴上找到并弹出来 x 3
- [ ]  家长说 “低音 So”，跳跳在琴上找到并弹出来 x 3
- [ ]  家长打乱说 “高音 Fa / 低音 So / 高音 Fa / 低音 So” 各 1 次
- [ ]  一起唱 `Si-So-Fa` 3 次

> **家长看这里**：今天不要问太多知识定义，只看“能不能分出来”。如果找错了，直接指一下重新来，不用讲大道理。

### 环节二：主线任务（10分钟）— 《扬基歌》精练

- [ ]  唱《扬基歌》1 遍
- [ ]  把有 `Si-So-Fa` 的那一句单独唱 3 遍
- [ ]  那一句单独慢弹 3 遍
- [ ]  全曲再弹 2 遍
- [ ]  如果今天状态好，再完整唱弹连起来 1 遍

> **家长看这里**：这首曲子的主要任务是“唱清楚再弹清楚”。如果一弹就乱，就退回唱谱，完全没关系。

### 环节三：辨音小挑战（5分钟）— 《滑稽面孔》

- [ ]  先看谱子，找出高音 Fa 和低音 So 各 1 次
- [ ]  慢速弹《滑稽面孔》2-3 遍
- [ ]  哪个地方最容易看错，就停下来单独弹 2 遍

## 周五 5/15 — 冒险日

> 今天进入音乐城堡大冒险！三道关卡正好把这周最重要的内容串起来。

### 故事开始

家长读给跳跳听：

> *“跳跳今天来到音乐城堡门口。门卫说：‘想进去，得先唱出神秘咒语。进了城堡以后，还要分清两位长得有点像的精灵。最后穿过管风琴大厅，才能拿到本周的小星星宝箱！’”*

### 第一关：神秘咒语门（6分钟）— 《扬基歌》

- [ ]  跳跳先唱神秘咒语 `Si-So-Fa` 3 次
- [ ]  唱《扬基歌》1 遍
- [ ]  弹《扬基歌》2-3 遍
- [ ]  如果门还是没开，就把最容易混的那一句单独唱 2 遍、弹 2 遍

> **家长看这里**：这一关的重点是“先唱清楚”。孩子如果愿意，可以把 `Si-So-Fa` 唱得像口令、像魔法咒语一样，会更投入。

### 第二关：双胞胎精灵关（6分钟）— 《滑稽面孔》

家长读：

> *“城堡里住着一对双胞胎精灵，一个叫高音 Fa，一个叫低音 So。它们老爱躲起来，只有找对了，桥才会放下来。”*

- [ ]  在《滑稽面孔》的谱子里找出高音 Fa 1 次
- [ ]  再找出低音 So 1 次
- [ ]  慢速弹《滑稽面孔》2-3 遍
- [ ]  找错或弹混的地方，停下来单独补 2 遍

> **家长看这里**：这一关练的是“看清楚再弹”，不是练速度。找到了就夸“你把精灵认出来啦”。

### 第三关：管风琴大厅（6分钟）— 《教堂管风琴》

家长读：

> *“最后一扇门后面，是高高的管风琴大厅。里面的声音又长又稳，只有安安静静、稳稳当当弹的人，才能拿到宝箱。”*

- [ ]  弹《教堂管风琴》3 遍
- [ ]  选一小句再补 2 遍，让它更顺
- [ ]  过关奖励：弹《穿雨鞋在水中行走》1 遍庆祝一下

### 收尾（2分钟）

- [ ]  做《双臂上举与下垂》1 遍
- [ ]  家长宣布：“音乐城堡通关成功！”
