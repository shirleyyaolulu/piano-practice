# 每日练习计划模板

生成今日练习计划时使用以下框架结构。

---

## 模板

```
# 今日钢琴冒险 🎹

## 冒险等级：[根据学习阶段]
## 预计时间：20-30分钟
## 📊 今日练习配方：新内容 [X]% + 复习 [Y]% + 回顾 [Z]%

---

### 🌅 热身关卡（5分钟）——旧内容复习
**复习什么**：[从 skill_inventory 中选一个到期需要复习的旧技能]
**故事引入**：[一个小故事引出热身内容，和旧内容关联]
**活动**：[用旧内容做热身，比如以前学过的音阶、指法]
**家长提示**：[怎么判断孩子还记不记得，如果忘了怎么办]

### ⚔️ 主线任务（10-15分钟）——本周新内容
**故事引入**：[故事延续，连接到本周新学的重点内容]
**活动**：[当天的重点练习，分成2-3个小步骤]
**家长提示**：[常见问题及解决方法]
**如果卡住了**：[备选简化版本]

### 🔄 回忆挑战（3-5分钟）——旧曲目/旧技能
**回忆什么**：[从 pieces_log 中选一首之前学过的曲子或一个旧技能]
**活动**：[快速弹一遍旧曲子，或用旧技能做个小游戏]
**家长提示**：[如果孩子完全忘了也没关系，简单提醒一下就好]

### 🎮 挑战关卡（5分钟）
**挑战内容**：[一个有趣的小挑战，可以混合新旧内容]
**成功标准**：[什么算完成了]
**奖励**：[建议的鼓励方式]

### 🌙 收尾（2-3分钟）
**活动**：[轻松的收尾活动，回顾今天学到了什么]
**明日预告**：[给孩子一个期待]

---

### 📝 给家长的笔记
- 今日重点观察：[...]
- 下次课可以问老师：[...]
- 孩子的进步记录：[...]
- ✅ 练完后请告诉我练习情况，我会更新记录
```

## 使用说明

- 从 skill_inventory 中按间隔复习算法选择复习内容
- 新内容占 50-60%，到期复习占 20-30%，随机回顾占 10%
- 根据 current_stage 调整活动设计（如 single_finger 阶段不涉及指法切换）
- 练习结束后提醒家长反馈，以便更新记录
